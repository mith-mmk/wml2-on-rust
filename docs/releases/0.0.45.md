# WML2 0.0.45

## Changes
- Align the direct reader dependency with `bin-rs 0.1.0`, WebP with
  `webp-rust 0.5.0`, AVIF decoding with `avif-rust 0.3.0`, and ICC parsing
  with `icc-profile 0.0.8`, including the `wml2-test` tools.
- Update generated WASM verification manifests to the same reader version.
  Decoder/encoder source, fixtures and codec submodule pins are unchanged.

## Compatibility
- Public APIs exposing reader traits now use `bin-rs 0.1.0`. Callers providing
  readers must use the compatible reader dependency; this is a pre-1.0
  dependency compatibility change, without compatibility aliases or forks.
- Retain existing WML2 methods and codec features, including the legacy WebP
  adapter. The ICC upgrade adds defensive malformed-input bounds checks without
  changing profile specifications or supported color transforms. Existing AVIF
  encoder and JXL pins are unchanged.
- Default features and the Rust 1.91 minimum version are unchanged.
- Cargo treats 0.0.45 as a separate pre-1.0 compatibility interval from 0.0.44.
  Downstream consumers must select it explicitly. Viewer adoption follows the
  lower-level library releases.
