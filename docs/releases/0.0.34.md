# WML2 0.0.34

## Changes
- Add TGA encoding for true-color, grayscale and exact indexed images, with
  uncompressed or RLE output. Extend decoding with legacy 2/4-way interleave,
  TGA 2.0 alpha attributes and checks on pixel/metadata boundaries.
- Add PCX version-5 RGB and exact indexed encoding. Interpret supported legacy
  EGA/CGA palettes and check padded scanline and encoded-output budgets.
- Add uncompressed legacy BGRA8 DDS encoding and DX10 BC7 decoding for all
  eight modes. Honor supported DX10 alpha modes and validate compressed payloads.
  Inline the shared BC1 kernel to resolve the measured BC1 performance regression.
- Correct Q4/XLD4 repeat-color runs, removing horizontal bands. Validate run,
  block, input and output boundaries before reading or allocating. The corrected
  decoder matched RECOIL 6.4.5 in all RGB pixels of 28 reference images.
- Update the optional `avif-rust` decoder dependency and submodule to 0.0.8.
  The `avifenc-rust` dependency remains at 0.0.7 and `webp-rust` at 0.3.2.
- Gate GitHub Releases on the shared CI suite, an exact tag/commit/version match,
  version-specific notes and example archives from Linux, Windows and macOS.
  Add Issue/PR templates and release maintenance guidance.

## Compatibility
- Existing RGBA8 callbacks, options fields and default features are retained.
  Enable `tga`, `pcx`, `dds`, `pic2` or `q4` explicitly; `noretoro` disables these
  modules along with the other retro formats.
- Q4 output changes where the old decoder misinterpreted repeat-color runs.
  Malformed or over-budget inputs can now be rejected earlier; `expanded_bytes`
  bounds individual buffers/output sizes, not total peak heap or RSS.
- TGA indexed encoding preserves exact colors without quantization. TGA alpha
  attribute 2, ambiguous PCX CGA monochrome and DDS custom/reserved alpha modes
  are explicitly unsupported. DDS still decodes only the first mip of supported
  single 2D surfaces; BC6H/HDR, arrays, cubemaps and volume textures are unsupported.
- DDS sRGB formats retain stored channel values without an implicit transfer
  conversion. ImageBufferEx and JPEG2000 work are outside this release.
- Recorded paired benchmarks resolved the BC1 regression. BC7 differences of
  about +1.2% to +1.8% remain on the measured host; no universal zero-regression
  claim is made. See the [codec coverage](https://github.com/mith-mmk/wml2-on-rust/blob/v0.0.34/docs/codec-status.md),
  [DDS measurements](https://github.com/mith-mmk/wml2-on-rust/blob/v0.0.34/docs/dds-bc1-performance.md)
  and [Q4 validation](https://github.com/mith-mmk/wml2-on-rust/blob/v0.0.34/docs/q4-status.md).
