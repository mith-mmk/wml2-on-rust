# WML2 0.0.33

## Changes
- Update `webp-rust` from 0.3.1 to 0.3.2, bringing stricter VP8 decoding,
  animation header handling with ICC profiles, and corrected lossy chroma conversion.
- Refresh WebP lossy encoding byte snapshots for the corrected conversion,
  including RGBA output with alpha.
- Add repository guidance for temporary working folders and codec image checks.

## Compatibility
- No WML2 public API declarations or feature definitions were changed in this tag diff.
- Lossy WebP encoded bytes and sizes can change. Consumers comparing exact output
  bytes should update their expectations; stricter VP8 decoding can affect malformed input.
- This release retains the AVIF 0.0.7 dependency. The subsequent AVIF 0.0.8 update
  and the separate ImageBufferEx work are outside this release.

## Pull requests
- None in this tag range: the release changes were direct commits.
