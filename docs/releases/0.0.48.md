# WML2 0.0.48

## Changes

- Raise the minimum compatible version of the optional `icc-profile` dependency from 0.1.0 to 0.1.1 for color-managed decoding. The workspace lockfile and the non-published test utility also use 0.1.1.
- Harden CI setup for FFmpeg-backed codec comparisons: restrict Ubuntu index downloads to the required package lists, retry transient index failures once, and use cache keys that accept multi-feature builds without changing the Cargo features under test.

## Compatibility

- WML2 introduces no public API, codec, or feature changes in this release. Builds without color management do not gain an ICC dependency. The minimum supported Rust version remains 1.91.
- As with prior 0.0.x releases, a downstream Cargo requirement of `0.0.47` does not select 0.0.48 automatically. Update the requirement explicitly to pick up this release.
