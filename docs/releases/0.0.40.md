# WML2 0.0.40

## Changes
- Fix baseline and progressive JPEG restart-interval handling, including
  intervals in final rows and progressive scans. Consume restart markers at
  MCU boundaries, reset prediction/EOB state, and reject missing or out-of-order
  markers rather than returning an incomplete image as a successful decode.
- Expose `orientation_applied: DataMap::Bool(true)` on JPEG XL output and retain
  the original coded value as `JPEG XL Source Orientation` (`DataMap::UInt`).
  The pinned jxl 0.7.4 already applies that transform to delivered pixels;
  consumers can use the marker to avoid applying source orientation twice.
  See the [orientation contract](../jpeg-xl.md#output-orientation-contract).
- Refine CI selection by codec impact, reuse prepared FFmpeg artifacts including
  hidden files, and add focused codec smoke checks. Main and release-tag checks
  retain full validation. Add the optimized, safety-checked CI test profile.

## Compatibility
- The public `DataMap` enum gains `Bool(bool)`. Downstream exhaustive matches
  must handle this variant; its display string is `true` or `false`.
- JPEG XL pixels are unchanged by the metadata addition. `true` suppresses a
  consumer's automatic source-orientation transform, not user-requested rotation.
  False, absent, or incorrectly typed markers retain legacy consumer behavior.
  Other codecs do not gain this marker in this release.
- JPEG files with valid restart intervals now decode completely; malformed
  restart sequences can fail instead of producing partial output with warnings.
  Default features, dependency versions, and submodule pins are unchanged.
- This is a pre-1.0 release: Cargo treats 0.0.40 as a separate compatibility
  interval from 0.0.39. Pin the intended version when adopting it downstream.

## Validation
- JPEG restart tests cover baseline/progressive scans, 48 restarted fixtures
  against plain-reference RGBA, malformed markers, limits, cancellation and draw
  failure. Prior image and benchmark evidence, including the approximately 3.4%
  progressive multithread timing increase in one local sample, is documented in
  [JPEG restart validation](../jpeg-restart-fix.md).
- JPEG XL regression coverage checks all eight orientations against independent
  reference pixels and verifies both metadata values in legacy and extended
  image buffers. The PR validation passed 28 JPEG XL tests; full ICC-path pixel
  agreement and external-plugin metadata transfer remain unverified.
- Release preparation validates the notes and the actual Cargo package, including
  its root README. The tag workflow runs full checks at the tagged commit and
  builds example archives on Linux, Windows and macOS before publication.
- This release publishes GitHub artifacts. crates.io publication is separate and
  is not performed by the release workflow. Viewer adoption remains separate.
