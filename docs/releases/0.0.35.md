# WML2 0.0.35

## Changes
- Explicitly select the repository's English README in the crate manifest.
  Cargo now includes it as the package-root `README.md`, allowing crates.io to
  display the crate documentation. The 0.0.34 package omitted this file.
- Update the English and Japanese README dependency examples and release links
  for 0.0.35. Add README inclusion to the release packaging checklist.

## Compatibility
- Documentation and package metadata only: decoder/encoder implementation,
  public APIs, default features and dependency versions are unchanged from 0.0.34.

## Pull requests
- None in this tag range: this README packaging fix is a direct release commit.
