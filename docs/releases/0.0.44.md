# WML2 0.0.44

## Changes
- Update the direct reader dependency to published `bin-rs 0.0.11`, the WebP
  codec to published `webp-rust 0.4.0`, and the AVIF decoder to published
  `avif-rust 0.2.0`. Update WASM verification harnesses to the same reader version.
- Update package metadata and current dependency examples to 0.0.44. This
  release preparation changes no decoder/encoder source or fixture data.

## Compatibility
- WML2 APIs that expose reader traits now use `bin-rs 0.0.11`; callers supplying
  readers must use that compatible dependency version. No compatibility alias,
  path override or codec source fork is introduced for this migration.
- The optional `icc-profile 0.0.7` dependency still uses an older reader internally.
  WML2 accesses ICC through its byte-slice API, so those reader traits do not cross
  the boundary. Existing JXL decoder/parser compatibility dependencies are unchanged.
- Default features, Rust 1.91 minimum version, codec behavior and submodule pins
  are unchanged. This is a dependency alignment release, not a new codec feature.
- Cargo treats 0.0.44 as a separate pre-1.0 compatibility interval from 0.0.43.
  Downstream consumers must select it explicitly. Viewer adoption is separate.

- The tag workflow runs full checks on the exact release commit and builds Linux,
  Windows and macOS example archives before creating the GitHub Release.
  Crates.io publication is separate and requires its own package verification.
