# WML2 0.0.46

## Changes

- Use the published icc-profile 0.1.0 backend for optional ICC color management.
- Add bounded CMYK conversion for supported JPEG, TIFF, and PSD paths, with explicit fallback warnings when managed conversion cannot be used.
- Include analytic regression tests, external-image validation tools, and ICC stage timing probes.
- Preserve best-effort recovery for corrupt later TIFF pages, while propagating CMYK ICC preparation and transform failures.

## Compatibility

- Cargo treats 0.0.46 as a separate compatibility interval from 0.0.45. Downstream applications must update their requirement explicitly.
- ICC color management remains optional through the color-management feature; enabling it also enables high-bit-depth support. Default-feature behavior is unchanged.
- Supported embedded CMYK profiles use ICC conversion to sRGB. Unsupported/missing profiles retain the documented fallback; this does not promise universal CMS accuracy.
- Rust 1.91 remains the minimum supported version.
