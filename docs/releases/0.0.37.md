# WML2 0.0.37

## Changes
- Add opt-in `image-buffer-ex` storage, callbacks and encoder requests for checked
  unsigned Gray/RGBA8,12,16 samples. Source declarations, stored layout and output
  requests remain independent. Byte strides, unaligned little-endian samples,
  borrowed views, straight alpha and explicit normalized Exact/Round conversion
  are checked before use.
- Add static PNG/TIFF/AVIF EX adapters, preserving native sample precision.
  Correct TIFF FillOrder handling and reject unsupported SampleFormat declarations.
  Update the optional AVIF dependencies to published `avif-rust 0.1.0` and
  `avifenc-rust 0.1.0`, sharing registry `avif-image-buffer 0.1.0`.
- Extend opt-in JPEG2000 EX decoding to unsigned Gray/RGB/declared straight RGBA
  at12/16 bits, including supported reversible5/3 and bounded irreversible9/7
  reconstruction. Retain native pixels through an owned canvas handoff and
  account for source, conversion and decoder workspace before output.
- Add explicit JPEG2000 native-resolution decode APIs. A reduction of n discards
  the finest n DWT resolutions rather than resizing a full-resolution image.
  Existing entry points and explicit zero retain full-resolution decoding.
  Retain all packet/header accounting while omitting discarded entropy payloads
  and high-resolution coefficient reconstruction.
- Fix GIF callback cancellation after the first frame: public decoding returns
  successfully on Abort, stops further input/callback work and finalizes once.
  Cover GIF87a/89a and EX-disabled/enabled builds, preserving real callback/input
  errors and normal animation pixels.

## Compatibility
- `image-buffer-ex` and `jpeg2000` remain opt-in; existing default features,
  legacy RGBA8 callbacks, options structs and native highres APIs are retained.
  AVIF0.1.0 is a dependency version; the WML2 release version is0.0.37.
- Source compatibility notice: AVIF public re-exports now originate from the registry0.1.0 crates. Applications
  that directly exchange standalone AVIF types with WML2 must align those
  dependencies and sources; types from the old0.0.8/0.0.7 or separate path crates
  are not interchangeable. Prefer the WML2 re-exports at API boundaries.
- EX storage16 is supported, while current AVIF EX encoding selects Gray/RGBA8
  or12 output; AV1 output16 is rejected. Existing native YUV/subsampling/10-bit
  and explicit RightShift APIs remain separate. ICC/CICP is retained as metadata
  without automatic colour transformation or output-profile inference.
- **AVIS is not guaranteed.** The published AVIF0.1.0 dependency retains the known
  inter/show-existing issue; animation, APNG and multi-page EX display are outside
  this release. No upstream codec repository is changed by this release.
- Nonzero JPEG2000 reduction supports its documented bounded profile. Signed or
  mixed precision, subsampling, HT, encoded ROI, palette/CMAP, sYCC/ICC and certain
  alpha/MCT layouts remain deferred. Multi-tile-part PPT is unsupported. All
  packet headers/extents are checked; discarded high-resolution entropy is not
  Tier-1 decoded or fully validated. Explicit zero preserves broader legacy
  acceptance. Whole input and canvas remain resident; logical resource budgets
  are not an RSS bound and reduced output does not guarantee a small budget.
- TIFF correctness fixes can change decoded pixels. Invalid/over-budget byte
  layouts or unsupported declarations can reject earlier. Performance records
  retain noisy/adverse results and broad intervals; no universal no-regression
  guarantee or exact cache/branch explanation is claimed.

## Validation
- Independent pixel readers, feature combinations, native/actual WASM, i686,
  callback/stride/alpha/precision and memory/performance checks are retained in
  the [EX AVIF report](../image-buffer-ex-avif.md),
  [JPEG2000 reduction specification](../jpeg2000-reduced.md) and
  [Gray32 follow-up](../jpeg2000-gray-regression.md).
- The JPEG2000 reduction corpus includes1,309 independent OpenJPEG references
  and96 large reduced outputs compared with OpenJPEG and FFmpeg. Reversible
  outputs match exactly; irreversible comparisons and supported-profile limits
  retain their documented tolerances and reservations.
- The GIF regression has a direct main/before/after public-API reproduction,
  independent pixel comparisons, callback/error checks and paired measurements;
  see the [GIF cancellation report](../gif-abort.md).
- Release publication is gated by shared feature/platform CI, exact tag/SHA/
  Cargo-version/release-body checks and example builds on Linux, Windows and macOS.
