# WML2 0.0.42

## Changes
- Move JPEG XL pixel decoding to published `jxl =0.8.0`, retaining the bounded
  still-image contracts for precision, orientation, metadata, cancellation and
  explicit sRGB conversion. Keep published `jxl =0.7.4` only as the parser-only
  pre-allocation and dimension-inspection compatibility dependency.
- Add bounded original-profile RGB8/16 JPEG XL animation with optional matching
  straight full-resolution alpha. Common callbacks, ImageBuffer and
  ImageBufferEx receive coalesced complete canvases with crop/reference/blend
  and orientation applied by the codec. Native RGBA16 output retains exact
  rational ticks; common callback waits must be exact integer milliseconds.
- Preserve loop counts, visible final-zero frames, source/output ICC separation,
  explicit per-frame sRGB conversion, cooperative cancellation and callback
  Abort/error semantics. Fully decode and validate the stream before publishing
  callbacks; admit retained canvases, prepared output, metadata and scratch
  cumulatively, including metadata held during nested animation decoding.
- Fix old-style JPEG TIFF files whose strips refer into an already complete
  JPEGInterchangeFormat stream, including the public `smallliz.tif` layout.
  Infer missing StripByteCounts only for a single uncompressed contiguous RGB8
  strip with an exact dimension-derived byte length; preserve bounds and limits.
- Reconcile both READMEs and current JPEG XL / ImageBufferEx guides, separate
  historical evidence from current contracts, and retire the old unreleased
  TIFF entry into these canonical notes. Decoder/encoder implementation is
  unchanged by the release-preparation documentation and version commit.

## Compatibility
- Default features, Rust 1.91 minimum version and AVIF submodule pins are
  unchanged. JPEG XL remains opt-in; its runtime is pure Rust with no new C/FFI,
  fork, vendored patch, public resource-policy API or fixed-cap increase.
- Animation is a bounded original-profile RGB8/16 subset. XYB animation,
  preview-bearing animation, timecodes, HDR/float output or tone mapping,
  associated/subsampled or mixed-depth animation alpha and general extra
  channels remain unsupported. The separate XYB follow-up #104 and the broad
  preview/HDR/extra-channel/resource development stack are not included.
- Static EX picking, encoding and conversion reject animated state rather than
  dropping frames. There is no JPEG XL encoder, original-JPEG reconstruction,
  preview extraction or resumable/provisional output API.
- All existing input, canvas, internal-layer, frame, metadata and workspace
  limits remain. Conservative requested-buffer admission is not a codec-wide
  heap or process-RSS guarantee. Large images may still be rejected, and
  cancellation remains cooperative without a latency bound.
- Other TIFF missing-count layouts, out-of-range strips, unsupported compression
  and invalid geometry still reject. Historical #71 evidence uses a public
  smallliz fixture and generated RGB8 patterns; it does not establish the
  pixels of an unavailable private `XING_T24.tiff` file.
- Cargo treats 0.0.42 as a separate pre-1.0 compatibility interval from 0.0.41.
  Select the intended version explicitly when adopting it downstream.

## Validation
- Historical implementation results and independent pixel-oracle, WASM,
  display and benchmark evidence are retained in
  [focused migration](../jpeg-xl-focused-integration.md),
  [bounded animation](../jpeg-xl-focused-animation.md) and
  [legacy TIFF](../tiff-legacy-layouts.md). Their original environments,
  revisions and performance tradeoffs remain part of those records.
- Windows x64 / Rust 1.99.0 release checks passed: default workspace 415 tests
  with 13 existing ignored; JXL library plus seven integration targets 115 tests;
  focused TIFF library/integration targets 131 tests; disabled JXL feature one
  test (the gated animation target correctly runs zero tests).
- Release/CI helper tests passed (35), along with canonical release-note
  validation, 111 relative documentation links, `cargo fmt --all --check` and
  `git diff --check`. Clippy passed in the existing warning mode; inherited
  warnings remain. No fresh browser/WASM/private-corpus/performance run is claimed.
- `cargo publish -p wml2 --dry-run --locked` passed package verification with
  845 files (9.6 MiB uncompressed, 6.8 MiB compressed). The actual package has
  a root README byte-identical to the repository README; its normalized
  manifest selects that file and pins the intended JXL decoder/parser versions.
- CI/CD completion is intentionally not awaited. Existing CI and tag-release
  gates are unchanged. The tag workflow creates GitHub Release example archives;
  crates.io publication is a separate operation. An uploaded crate must not be
  confused with a completed GitHub Release or downstream viewer adoption.
